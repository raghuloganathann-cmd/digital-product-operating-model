# Digital Product Operating Model

A simple web project that explains a digital product operating model and includes a maturity self-assessment.

## Files
- index.html : page structure
- style.css  : styling (light and dark mode, responsive)
- script.js  : content (LAYERS array), layer explorer and maturity score logic

## How to run
Open index.html in any web browser. No installation is needed.

## How to customise
Edit the LAYERS array in script.js to change layer names, practices, roles and measures.
